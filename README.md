# Core JavaScript

Small JavaScript snippets and notes for learning core language features.

## Contents

- `variables.js`, `variables2.js` — variable declarations and basics
- `closure.js` — closure examples
- `datatypes/` — datatype-focused examples
- `spread-rest/` — spread/rest operator examples

## Run

Most files can be run directly with Node.js:

```bash
node closure.js
```
